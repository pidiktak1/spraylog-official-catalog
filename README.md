# SprayLog Official Pesticide Catalogue

Public update feed for the **Καταγραφή Ψεκασμών** Windows and Android applications.

This repository contains only public information generated from the official ΥΠΑΑΤ pesticide database. It does not contain application source code, OneDrive files, spray records, photos, or other personal data.

The catalogue is refreshed automatically every day by GitHub Actions. The applications read:

- `catalog/manifest.json`
- `catalog/official-pesticides.js.gz`
- `catalog/official-pesticides.js`

Official source: <https://1click.minagric.gr/oneClickUI/frmFytoPro.zul>
